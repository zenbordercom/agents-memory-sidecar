returned a transient 404. That later verification step made the workflow appear
failed even though npm had accepted the package. The release was recovered
without republishing or rewriting either tag:

1. Confirmed `agents-memory-sidecar@0.3.1` and the `latest` dist-tag on npm.
2. Confirmed provenance, signature, shasum, and integrity metadata.
3. Added the npm tarball and integrity text to the existing GitHub Release.
4. Added bounded registry retries in commit `49f6e95` so future releases wait
