# v0.3.2 P0 Security And Release Closure

Status: in progress
Date: 2026-08-04
Target release: v0.3.2

## Goal

Close the security and documentation gaps found during the post-v0.3.1 review
without expanding the product surface. This is a maintenance release.

- [x] Upgrade `@modelcontextprotocol/sdk` from 1.29.0 to 1.30.0 or newer.

  `ip-address`.

- [x] Add dependency audit gates to CI and tagged releases.
