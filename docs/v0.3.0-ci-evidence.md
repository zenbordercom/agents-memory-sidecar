## Node Compatibility

The CI matrix passed on Node.js 22 and 24. Both jobs ran install, typecheck,
build, documentation checks, unit tests, fake-store smoke, HTTP smoke, HTTP
bridge smoke, and fail-closed security smoke. The Node 24 job also passed the
critical-module coverage threshold.

Coverage is intentionally evaluated on Node 24 only. Node 22's V8 coverage
mapping with `tsx` undercounts TypeScript lines despite passing the same tests;
the Node 22 compatibility gate remains functional validation rather than a
duplicate instrumentation gate.

## PostgreSQL And Search

The CI PostgreSQL job used `pgvector/pgvector:pg16` and passed:

```text
npm run db:migrate
npm run postgres:smoke
npm run search:benchmark
```

`postgres:smoke` completed migration and lifecycle checks. The benchmark ran
against PostgreSQL with fixture model `fixture-3d-v1` and dimension `3`; it
reported keyword, semantic, and hybrid measurements with latency, result count,
`recall_at_5`, reciprocal rank, actual mode, model, and fallback fields.
Semantic and hybrid fixture queries each reported `recall_at_5: 1`. The
embedding-not-configured scenario reported the deliberate hybrid-to-keyword
fallback.
